大学那会儿我对区块链特别上头，天天啃底层：区块链的数据结构是什么样，Merkle Tree 怎么把交易串起来，SHA256 哈希、RSA/ECC 加密这些。还去读了以太坊的源代码，写过智能合约，给学校实验室搭了一个私有链平台，也在区块链的岗位实习过。可以说区块链是我编程的起点，我会 Go 这门语言，就是因为做区块链才学的。不过毕业后没往这个方向走，相关认知基本停在 2021 年左右，后来什么跨链、链下、闪电网络这些新东西就没再跟了。

毕业后的第一份工作是做 Golang，第一个正经项目是身份认证系统，把 OAuth2、OIDC、RBAC 这些权限相关的东西摸了一遍，算正式入了后端这道门。日常就是写业务，CRUD 写多了，数据库、缓存、队列、网关这些中间件也慢慢熟了。再后来跟着公司里的大佬了解了一点 k8s，自己也补了补 k8s 的架构，各种 workload 什么时候该用心里大概有数。这家公司干了两年，因为一些原因离职了。

第二家公司一开始做的是工业软件——工业布匹的智能质检，用的 Java 和 ROS2。做了一年左右，说实话不太喜欢，就转了个组去做 k8s 模型训练平台。在这家公司主要用 Python，做着做着越来越像 DevOps：系统自己设计、自己开发、自己部署到 k8s，集群也得自己运维。

再往后 AI Agent 火起来了，业务也跟着转向做 Agent 应用。不过我的活儿还是 DevOps 那一摊：系统设计、CI/CD、可观测性、功能开发、集群部署，基本全都能上。ReAct Agent、工具调用、MCP、CLI 这些也都有了解。
